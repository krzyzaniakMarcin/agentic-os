# T4 — Harness Poll Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shared, harness-driven poll loop (`run_agent`) plus the `Agent` step-contract and `Role` config type that every Phase 0 runtime drives through.

**Architecture:** The *harness* owns the loop, not the model (arch §6). `run_agent` keeps a per-agent cursor, reads new subscribed events (excluding the agent's own emissions unless `see_own_events`), invokes `agent.step(new_events)` only when there are matching events, forwards any returned emits to the log, and records one `agent.step` event (`saw_events` window + `usage`) per step for replay/cost. `base.py` defines the `step() -> (emits, usage)` contract and the `Agent` base holding loop-facing state; `role.py` is the role dataclass + a dict loader. T5's Claude Code runtime subclasses `Agent`; here we test the loop with an in-process fake.

**Tech Stack:** Python 3.12, asyncio, asyncpg (via existing `substrate.log`), pytest + pytest-asyncio.

## Global Constraints

- Python `>=3.12`; async-first (`async def`, `await`) throughout, matching `substrate/log.py` and `substrate/mcp_server.py`.
- The loop calls the **existing** `substrate.log` API verbatim — do not change `log.py`:
  - `await log.read_events(run_id, since_id=0, types=None, correlation=None, limit=50, exclude_agent=None) -> list[dict]` — each event is a dict with integer key `"id"`, plus `type`, `payload`, `agent`, `run_id`, `reply_to`, `correlation`.
  - `await log.emit(agent, type, payload, run_id, reply_to=None, correlation=None) -> {"id", "ts"}`.
- **Self-exclusion is the harness's job, never the MCP tool's** (arch §5, §6): the read passes `exclude_agent=self.name` unless the role opts into `see_own_events`.
- **No double-emit** (T4 note): the CC runtime returns `emits=[]` and the loop emits **only** `agent.step`. The `step() -> (emits, usage)` contract still forwards real emits (for other runtimes), so the per-emit branch stays and must be tested.
- `agent.step` payload shape (arch §4, §6): `{"step_n": <int>, "saw_events": [from_id, to_id], "usage": <dict>}`. The `{"v": 1}` envelope key is added by `log.emit`, not here.
- Tests: mirror `tests/test_mcp_server.py` conventions — module-level `async def test_*`, `pytest` asyncio mode already configured. Loop-logic tests monkeypatch `substrate.log` so they need **no** database; the one integration test needs Postgres up (`docker compose up db`).

```python
"""Agent role config (arch §6, §7): subscriptions + prompt drive one poll loop."""
from dataclasses import dataclass, field, fields


@dataclass
class Role:
    name: str
    subscribes_to: list[str]
    emits: list[str] = field(default_factory=list)
    prompt: str = ""
    see_own_events: bool = False  # deliver the agent's own emissions back to it? (arch §6)
    tick_s: float = 0.5  # idle poll interval


def load_role(data: dict) -> Role:
    """Build a Role from a config dict, dropping keys Role doesn't model."""
    known = {f.name for f in fields(Role)}
    return Role(**{k: v for k, v in data.items() if k in known})
```

```python
"""Runtime contract (arch §6): the poll loop drives step(); step turns new
events into (emits, usage). Subclasses (e.g. the Claude Code runtime, T5)
implement step(); the CC runtime returns emits=[] because the model emits
through the substrate MCP directly."""
from dataclasses import dataclass

from agent.role import Role


@dataclass
class Emit:
    type: str
    payload: dict
    reply_to: int | None = None
    correlation: str | None = None


class Agent:
    def __init__(self, role: Role, run_id: str):
        self.name = role.name
        self.run_id = run_id
        self.subscribes_to = role.subscribes_to
        self.see_own_events = role.see_own_events
        self.tick_s = role.tick_s
        self.step_n = 0
        self._stopped = False

    @property
    def stopped(self) -> bool:
        return self._stopped

    def stop(self) -> None:
        self._stopped = True

    async def step(self, new_events: list[dict]) -> tuple[list[Emit], dict]:
        raise NotImplementedError
```

## Task 3: The poll loop

**Files:**
- Create: `agent/poll_loop.py`
- Test: `tests/test_poll_loop.py`

**Interfaces:**
- Consumes: `Agent`, `Emit` from `agent/base.py`; `substrate.log` (`read_events`, `emit`).
- Produces:
  - `async def run_agent(agent: Agent, cursor: int = 0) -> None` — loops while `not agent.stopped`:
    1. `events = await log.read_events(run_id=agent.run_id, since_id=cursor, types=agent.subscribes_to, exclude_agent=None if agent.see_own_events else agent.name)`
    2. If empty: `await asyncio.sleep(agent.tick_s)`; continue.
    3. Else: `saw = [events[0]["id"], events[-1]["id"]]`; `emitted, usage = await agent.step(events)`; forward each `Emit` via `log.emit`; `agent.step_n += 1`; `log.emit(... "agent.step", {"step_n": agent.step_n, "saw_events": saw, "usage": usage} ...)`; `cursor = events[-1]["id"]`.

```python
"""The harness drives the loop, not the model (arch §6). One shared loop for
every runtime: cursor per agent, read new subscribed events (self excluded
unless see_own_events), invoke step() only when there's something to react to,
forward emits, and record one agent.step (saw_events + usage) for replay/cost.
While idle it costs zero tokens."""
import asyncio

from agent.base import Agent
from substrate import log


async def run_agent(agent: Agent, cursor: int = 0) -> None:
    while not agent.stopped:
        events = await log.read_events(
            run_id=agent.run_id,
            since_id=cursor,
            types=agent.subscribes_to,
            # self-exclusion lives here, never in the MCP tool (arch §5, §6)
            exclude_agent=None if agent.see_own_events else agent.name,
        )
        if not events:
            await asyncio.sleep(agent.tick_s)
            continue
        saw = [events[0]["id"], events[-1]["id"]]
        emitted, usage = await agent.step(events)
        for e in emitted:  # inert for the CC runtime (emits=[]); real for others
            await log.emit(
                agent.name, e.type, e.payload, run_id=agent.run_id,
                reply_to=e.reply_to, correlation=e.correlation,
            )
        agent.step_n += 1
        await log.emit(
            agent.name, "agent.step",
            {"step_n": agent.step_n, "saw_events": saw, "usage": usage},
            run_id=agent.run_id,
        )
        cursor = events[-1]["id"]
```
